# Controle de Lavagens

Agenda da lavação profissional. **Não é o ChordBook.** Pasta própria:

`C:\Users\Jairo\Desktop\ControleDeLavagens`

## O que faz

- **Hoje** — fila do dia, recebido, por cobrar
- **Agenda** — calendário e marcação por hora
- **Clientes e veículos** — nome, WhatsApp, matrícula, tipo (citadino, SUV…)
- **Preços** — tabela por serviço e tamanho do carro
- **Lembretes** — quem já passou os dias da última lavagem; um toque no WhatsApp
- **Caixa** — recebido e pendente no mês
- **Equipa** — quem lava
- **Cópia** — exportar / restaurar JSON neste telemóvel

Os dados ficam **só no aparelho** (não vai para a Play).

## Abrir no computador

Dê dois cliques em `index.html`, ou no Chrome abra a pasta.

## Abrir no telemóvel

No Chrome, com o computador e o telemóvel na mesma rede, use o endereço que o Cursor mostrar (porta 8765). Depois: menu → **Adicionar ao ecrã inicial**.

## Primeiro uso

1. **Começar com a minha oficina** — vazio, para o seu negócio.
2. **Ver um dia de exemplo** — três clientes fictícios para ver a agenda a trabalhar.

Em **Mais → Oficina** ponha o nome, o WhatsApp e de quantos em quantos dias lembrar (30 por defeito).
